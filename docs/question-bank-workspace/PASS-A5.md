# Pass A (round 5): the first questions on every NC 2017 standard

QB=<the workspace folder: see README.md>

Your task names PARTs `a5-<topic_id>`, each one North Carolina 2017 standard. First read
`$QB/WRITER-NC17.md`; every rule there applies, with these changes.

- **Write 30 questions per PART: 10 at difficulty 1, 10 at 2, 10 at 3.** This first pass gives every
  standard a usable set quickly; a later pass adds more on the same standard, so put the most central
  skills first and make these 30 the best of what the standard offers.
- **Cover the whole standard within the 30.** List the skills its summary names; every skill gets at least
  one question (and the core skills one at each difficulty), no skill more than about a fifth.
- **Choice questions: the key must not stand out.** Across a part, the correct option should be the
  strictly longest of its four in no more than about a quarter of the choice questions, and the strictly
  shortest in no more than about a quarter. Every option ends the same way (all with a full stop, or none).
- **Stay on this standard.** The blind solver flags a question that tests a neighbouring standard instead
  (place value in a reading-numerals standard, an unknown addend solved by subtracting in an adding
  standard, a bare equation in a word-problem standard, a remainder in a factors-and-zeros standard). Every
  question must need the skill this summary names, not only touch its topic.
- If part of the standard cannot be tested fairly in text, write fewer and say why in "notes".
- Lint to 0 and re-read as the base brief says. A writer's generator script, if any, goes in
  `$QB/scripts/` named after the PART.

Do not edit anything outside $QB/drafts and $QB/scripts.

Reply briefly per part: count by difficulty and kind, skills with rough counts, anything unsure or left out.
